# 国产大模型实战观察素材 2026-05-06

## 主题

不看跑分，只看实战：国内大模型到底谁更好使。

## 背景

最近国内大模型又更新了一轮，讨论热点集中在：

- Kimi 2.6
- GLM 5.1
- Qwen 3.6
- DeepSeek V4

很多宣传都在强调“最强”“跑分领先”，但真实使用者更在意的是：

- 日常到底顺不顺手
- 能不能直接看图排错
- 代码场景够不够稳
- 法律、文书、复杂文本对抗时推理是否靠谱
- 价格、稳定性、可用性是否适合长期用

## 原始体感摘要

### 总判断

选大模型，第一个判断标准不只是“谁更聪明”，而是它能不能直接看图。

真实编程排错时，用户最自然的动作往往不是复制日志，而是截图给 AI 看。尤其是：

- 代码报错截图
- 长页面报错
- 控制台截图
- 混合中英文提示

从使用体感看，截图上传和复制粘贴格式化文本相比，效率差距非常大。

## 编程模型锐评

### 第一梯队

#### GPT 5.5

- 工程场景最稳
- API 生态最广
- 性价比很强，适合高频调用
- 界面审美和前端 UI 细节还需要继续打磨

#### Claude Opus 4.6 / 4.7

- 上下文理解最深
- UI 和产品语境最懂人
- 适合复杂理解和高要求输出
- 明显更贵

结论：双王并列，没有绝对第一。

### 第二梯队

#### GLM-5.1

- 是最接近第一梯队的国产模型之一
- Agent 能力已经能贴着国际第一梯队打
- 缺点是慢、波动、不够稳定
- 用户多时资源紧张，套餐和调用体验会受影响

#### Kimi 2.6

- 潜力很强
- benchmark 表现漂亮
- 但实际使用偶尔会掉链子
- 纸面成绩和体感之间仍有差距

#### DeepSeek V4

- 写代码很“老实”
- 不乱发挥
- 套路代码、常规工程代码又快又稳
- 目前没有 Coding Plan 的情况下，用户编程场景的成本感知仍偏贵

#### Gemini

- UI、前端、视觉表达更强
- 工程类任务偏弱
- 是典型偏科生

## 图片理解观察

目前国内主力的图片理解编程模型，讨论重点在：

- Kimi 2.6
- Qwen 3.6 Max
- GLM-5V

### Kimi 2.6

- 代码截图体验最流畅
- 识别准确率高
- 长截图、密集报错、中英文混合场景都比较稳

### Qwen 3.6

- 也能用
- 整体还不错
- 但偶尔会漏行

### GLM-5V

- 代码截图识别相对弱一些
- 会出现漏行
- 也会出现符号识别错误
- 在严谨排错场景下不够让人放心

## 文本推理与法律文书观察

在日常小程序开发、云函数、前端代码这些场景中，Kimi 2.6 和 GLM 5.1 的体感差距并不大。

如果一定要区分，GLM 5.1 似乎略强一点点。

但在纯文本深度逻辑推理场景里，GLM 表现更好。

特别是在以下任务中：

- 法律纠纷应诉文书
- 代理意见
- 证据梳理
- 文书对抗和相互评议

使用体验表明，GLM 5.1 在纯文本法律文书对抗场景里，已经非常接近国际一线模型。

一个重要观察是：

- GLM 5.1 和 Claude Sonnet 4.6 的表现已经非常接近
- 双方各有所长
- GLM 在这类任务里的表现超过了 Gemini 3.1 Pro
- 而 Kimi 等其他国产模型，在法律文书生成方面普遍不如 GLM

## 其他模型观察

### 豆包

- 严重偏科
- 多模态底子很强
- 图片、视频能力在国内很强
- 但通用逻辑推理偏弱
- 长文本能力不足
- 专业生产力场景不占优
- 战略重心更偏短视频和直播生态

### Qwen 3.6 Max

- 中庸型模型
- 视觉、代码、文案、逻辑都不差
- 但也都不是最强
- 适合“不想踩坑，但也不追求单项极致”的用户

### Minimax

- 曾经价格优势明显
- 但有两个明显短板：
  - 不支持图片理解
  - 逻辑推理明显弱一档

### DeepSeek V4

- 当前被很多人视为性价比之王
- 编程能力明显追上来了
- 一旦图片模式成熟，格局可能快速变化

## 可提炼的结论

1. 图片理解已经不是加分项，而是日常实战的重要门槛。
2. 编程任务不只是看代码生成，还要看排错、截图识别、稳定性和成本。
3. GLM 5.1 在复杂文本推理，特别是法律文书类场景中非常值得重视。
4. Kimi 在截图排错体验上更有优势。
5. Qwen 更像全能均衡型选手，但不一定是单点最强。
6. DeepSeek V4 在“稳、老实、性价比”这一侧很有竞争力。
7. 豆包更像内容和多模态平台型能力，不是当前通用生产力的主答案。

## 适合延展的选题

- 不看跑分，只看实战：国产大模型到底谁更好使
- 代码截图排错时，Kimi、Qwen、GLM 到底谁更稳
- 法律文书、复杂文本推理场景，GLM 5.1 为什么值得重看
- DeepSeek V4 为什么会被很多开发者视为性价比之王
- 国内大模型怎么选：看图、写代码、做推理、控成本四条线
- 日常开发者到底该怎么选模型，而不是看排行榜
