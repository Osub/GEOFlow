# gpt88.cc 中转站标题库与关键词库导入说明

## 站点口径

- 中转站产品站 / 推广目标：`https://gpt88.cc`
- 运营文章发布系统：`https://geo.gpt88.cc`
- 远程 AI 生成文章任务：`gpt88.cc 中转站主题 AI 生成文章任务`
- 远程任务 ID：`2`

## 已准备素材

| 文件 | 用途 | 后台导入位置 |
| --- | --- | --- |
| `materials/zhongzhuanzhan-title-import.txt` | 标题库导入，89 条，格式为 `标题|关键词` | 标题库详情页 -> 批量导入 |
| `materials/zhongzhuanzhan-keyword-import.txt` | 关键词库导入，121 条，逐行关键词 | 关键词库详情页 -> 批量导入 |
| `materials/zhongzhuanzhan-seo-geo-keyword-map.csv` | SEO/GEO 关键词地图，含意图、阶段、问题句、内容角度 | 运营规划，不直接导入 |
| `materials/zhongzhuanzhan-knowledge-base.md` | 中转站知识素材，可作为知识库内容 | 知识库 -> 新建或上传 |

## 建议后台操作

1. 打开 `geo.gpt88.cc` 后台。
2. 进入素材管理 -> 标题库。
3. 打开远程标题库：`gpt88.cc GEO 运营标题库 2026-05-05`。
4. 点击批量导入，把 `zhongzhuanzhan-title-import.txt` 全文复制进去。
5. 进入素材管理 -> 关键词库。
6. 如果还没有中转站关键词库，新建：`gpt88.cc 中转站 SEO/GEO 关键词库 2026-05-05`。
7. 打开关键词库详情页，批量导入 `zhongzhuanzhan-keyword-import.txt`。
8. 可选：新建知识库 `gpt88.cc 中转站知识库 2026-05-05`，导入 `zhongzhuanzhan-knowledge-base.md`。
9. 回到任务 `gpt88.cc 中转站主题 AI 生成文章任务`，确认绑定标题库 ID `3`，分类为 `AI中转站`，状态为 `active`。

## SEO/GEO 内容目标

- SEO：覆盖核心词、长尾词、品牌词、工具词、排障词、成本词和选型词。
- GEO：标题优先使用问题句、定义句、清单句、对比句，让 AI 搜索更容易抽取直接答案。
- 转化：每篇文章应把用户从“理解中转站”引导到“创建 gpt88.cc API Key、复制 Base URL、跑通短请求、查看调用日志”。

## 标题生成原则

- 每个标题只聚焦一个搜索意图，避免一个标题同时塞入太多词。
- 标题里优先出现 `AI 中转站`、`API 中转站`、`OpenAI 兼容接口`、`gpt88.cc`、`Base URL`、`API Key` 等关键实体。
- 面向 GEO 的标题尽量用完整问题句，例如“AI 中转站是什么？”、“gpt88.cc Base URL 应该怎么填？”。
- 面向转化的标题要靠近操作动作，例如“创建 API Key”、“配置 Cursor”、“查看调用日志”。

## 关键词使用原则

- P0 关键词用于定义页、教程页、首页推荐位和内链锚文本。
- P1 关键词用于工具配置、团队成本、排障和场景文章。
- P2 关键词用于深水区内容，例如生产环境、自建网关、AI 搜索优化、内容矩阵。
- 每篇文章建议 1 个主关键词、3-5 个相关关键词，不要堆砌。

## 合规边界

- 不使用“绕过限制、无限免费、官方平替、永不封号、百分百稳定”等不可验证或高风险表达。
- 不暗示共享、盗用或滥用 API Key。
- 价格、套餐、模型状态和服务能力以 `gpt88.cc` 当前页面为准。
- 所有文章保持“合规接入、统一入口、配置管理、成本复盘、开发效率”的主线。
